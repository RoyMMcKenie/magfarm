# Changelog

## 0.1.0 — Foundation

- Created the documented MagFarm Lua package foundation.
- Added Manual, Camp, and Follow mode state structure.
- Added per-server/per-character persistent configuration.
- Added class preflight, spellbook role detection, group/Main Assist warning foundation, pet/mercenary status foundation, and a non-blocking ImGui control window.
- Added a scan-only Spell Acquisition foundation and permanent source attribution for `scribe.mac` by Sym, including the recorded contributions from Chatwiththisname, Lemons, and Sic.
- Autonomous camp pulling, vendor purchases, scribing execution, and mercenary command control are intentionally deferred until client-specific command paths are verified in-game.
